How it's built

No RAG, no vector database, no agent framework. Small, chained calls with strict output contracts.

ContextNarrow before you prompt

Keyword scoring cuts 676 pages to the ~58 that matter before any model call, which keeps cost under $1 and the context focused.

Output contractSchemas, not chat

Each call returns fixed JSON fields. Missing data comes back as null, and the prompt forbids guessing.

TraceabilityEvery number has a page

Page markers are injected into the text, so each extracted value and finding cites its source.

WorkflowExtract, then reason

Two extraction calls produce clean data, and a third reasons over that data instead of raw text. One reusable function runs any company with no custom logic.

ReliabilityPlan for failure

Long outputs hit the token limit and broke the JSON. The pipeline flags the parse failure, and just that step re-runs with a higher limit.

Human in the loopFindings are leads

The model's output is a starting point. Every finding cites pages so it can be checked, and I verified the Schneider gap against the report by hand.

Next: a labeled benchmark of reports with known issues, to measure how many real problems it catches and how often it's wrong.
